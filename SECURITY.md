# Security Policy

## Supported Versions

Security fixes are applied to the `main` branch.

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Use GitHub private vulnerability reporting for this repository (Security Advisories) so details stay confidential while a fix is prepared.

If private reporting is unavailable, contact the repository owner directly through GitHub and include:

- A clear description of the vulnerability
- Reproduction steps or proof of concept
- Impact assessment (what data or systems are affected)
- Any suggested remediation

## Response Targets

- Initial acknowledgement: within 72 hours
- Triage decision: within 7 days
- Fix timeline: depends on severity and complexity

We prioritize vulnerabilities that affect data integrity, remote code execution, credential exposure, and supply-chain risk.
